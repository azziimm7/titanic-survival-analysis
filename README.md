# Titanic EDA Project 🚢

This project explores the Titanic dataset from Kaggle.

## 📊 Key Analysis
- Survival rate analysis
- Survival by gender, class, and age
- Outlier detection in Fare
- Feature engineering (AgeGroup)

## 🛠️ Tools Used
- Python
- Pandas


## 📁 Dataset
Titanic - Machine Learning from Disaster (Kaggle)
